# Zeekret Dash: ฟีเจอร์ทั้งหมด

แอปสำหรับหน้าจอกลาง (head unit) ของ **Zeekr 7X**: กล้องจุดบอดขึ้นบน HUD และจอกลางเมื่อเปิดไฟเลี้ยว,
กระจกมองหลังดิจิทัล, กล้องติดรถ 4 กล้อง, ควบคุมรถ และระบบอัตโนมัติ

[English README](../../README.md) · [ระบบอัตโนมัติ](automation.md) · [ประวัติเวอร์ชัน](../../CHANGELOG.md)

> แอปทดลอง ไม่ใช่ของ Zeekr / Geely / ECARX และไม่ได้รับการรับรองด้านความปลอดภัย ไม่ได้แทนกระจกข้าง
> กล้องรอบคันหรือระบบเตือนจุดบอดของรถ มองด้วยตาเองทุกครั้งก่อนเลี้ยวหรือเปลี่ยนเลน ใช้งานด้วยความเสี่ยงของคุณเอง
> ทดสอบกับ Zeekr 7X (SEA) เท่านั้น

## ติดตั้ง
1. เปิดเบราว์เซอร์ **บนจอกลางของรถ** ไปที่ **zeekret.pages.dev** แล้วกด **Download** ที่ Zeekret Dash
   (เปิดลิงก์บนมือถือหรือคอมพิวเตอร์จะติดตั้งลงรถไม่ได้)
2. ติดตั้ง **ผ่าน App Lab** เหมือนแอปภายนอกอื่นๆ ของ 7X
3. ติดตั้งเสร็จให้กด **Back** (มุมซ้ายบน) **ไม่ใช่ Open** ไม่อย่างนั้นตัวติดตั้งอาจค้าง
4. เปิด **Zeekret Dash** แล้วอนุญาต **แสดงทับแอปอื่น**, **กล้อง** และ **การแจ้งเตือน**
5. เปิดไฟเลี้ยว: ภาพกล้องด้านนั้นจะขึ้น ปิดไฟเลี้ยว: ภาพหายไป

อัปเดตติดตั้งทับของเดิมได้ การตั้งค่าและไลเซนส์ยังอยู่ เสียบ USB ไว้สำหรับกล้องติดรถและการสำรองการตั้งค่า

## หน้า Home
การ์ดเรียงแถวละ 3 ใบ **แตะ** เพื่อสั่งงาน **กดค้าง** เพื่อเปิดการตั้งค่าของการ์ดนั้น

| แถว | การ์ด |
|---|---|
| 1 | Blindspot camera · Show it on · Rearview mirror |
| 2 | Mirror view · Car's blindspot lamp · Night dimming |
| 3 | Dash cam · Automation · Trailer mode |
| 4 | Acceleration mode · Steering · Damping |
| 5 | Rear fog light · Licence · About |

รถที่ไม่ใช่รุ่น Performance (ไม่มีช่วงล่างปรับได้) การ์ด Damping ยังอยู่ที่เดิม แต่เป็นสีจาง และขึ้นว่า **Not available**

## กล้องจุดบอด (Blindspot camera)
เปิดไฟเลี้ยว ภาพกล้องด้านนั้นจะขึ้น ปิดไฟเลี้ยวภาพหายไป ไฟฉุกเฉินไม่แสดงอะไร
- **Show it on:** HUD (ค่าเริ่มต้น), จอกลาง หรือทั้งสอง
- **ทำงานเมื่อ:** ตลอดเวลา (ค่าเริ่มต้น) หรือเฉพาะตอนขับ (เกียร์ D)
- ภาพฟิชอายถูกปรับให้ตรงเป็นภาพปกติ มองไปตามข้างรถไปทางด้านหลัง และกลับด้านเหมือนกระจกจริง
- ภาพบน HUD **เลื่อนเข้า-ออก** จากขอบด้านนอก (0.2 วินาที) ขนาดภาพพอดีกับส่วนของ HUD ที่มองเห็นจริง
- ภาพบนจอกลาง: เล็ก / กลาง (ค่าเริ่มต้น) / เต็มจอ ด้านขวา
- **Aim:** ปรับมุม ยก ระดับขอบฟ้า ความกว้างภาพ พร้อมภาพตัวอย่างสด
- **Display:** ความกว้างภาพ HUD, ความโปร่งใส HUD และปุ่ม **แสดงกรอบบน HUD 10 วินาที**
- **Night dimming:** หรี่ภาพตอนกลางคืน ตั้งความสว่างกลางคืนแยกได้

## ฟีเจอร์ความปลอดภัย (Blindspot ▸ Camera ▸ Safety)
| ฟีเจอร์ | ทำอะไร | ค่าเริ่มต้น |
|---|---|---|
| ค้างไว้จนพวงมาลัยตรง | ยกเลิกไฟเลี้ยวกลางโค้ง ภาพยังค้างจนพวงมาลัยตรง | เปิด |
| เลี้ยวไม่เปิดไฟเลี้ยว | ต่ำกว่า 30 กม./ชม. หมุนพวงมาลัยเกิน 90° โดยไม่เปิดไฟเลี้ยว แสดงด้านนั้น | เปิด |
| ลืมเปิดไฟเลี้ยว | เกิน 60 กม./ชม. หักพวงมาลัยเร็วโดยไม่เปิดไฟเลี้ยว แสดงด้านนั้น (ต่ำ / กลาง / สูง) | เปิด |
| เตือนเปิดประตู | เมื่อรถเตือนว่ามีอะไรมาขณะจะเปิดประตู แสดงกล้องด้านนั้น | เปิด |
| ไฟเตือนจุดบอดของรถ | ไฟที่กระจกข้างติด ภาพด้านนั้นมีขอบแดงกะพริบ เกิน 60 กม./ชม. เปิดกล้องให้แม้ไม่เปิดไฟเลี้ยว | เปิด |

## กระจกมองหลังบนจอกลาง (Rearview mirror)
เปิดด้วยการ์ด **Rearview mirror** ปุ่มกระจกจะขึ้นเมื่ออยู่เกียร์ D
- **Mirror view:** Rearview (กล้องหลัง), **Slide-in** (ค่าเริ่มต้น: ภาพหลังตรงกลาง ภาพจุดบอดซ้าย-ขวาเลื่อนเข้ามาเมื่อจำเป็น), Blindspot (ภาพสองข้าง)
- ลากเพื่อย้าย บีบนิ้วเพื่อย่อขยายได้ทุกเมื่อ ปุ่ม **Reset** ขึ้น 5 วินาที
- **กันแสงจ้ากลางคืน:** ปิด / ต่ำ (ค่าเริ่มต้น) / สูง ลดแสงไฟหน้ารถคันหลัง
- ตั้งค่า: ความโปร่งใส, ซูม / ความสูง / มุมของ Slide-in, ซูม / ความสูง / ใน↔นอก ของ Blindspot, มุมกล้องหลัง, ปุ่มรีเซ็ต

## กล้องติดรถ (Dash cam)
- บันทึก **ทั้ง 4 กล้องรอบคัน** เป็นภาพเดียว 2560×1440 ขณะขับ คลิปละ 1 นาที
- เก็บลง **USB** (โฟลเดอร์ ZeekretDash) หรือหน่วยความจำรถ พื้นที่ใกล้เต็มจะลบคลิปเก่าสุด
- ประทับ **วันที่ เวลา ความเร็ว** ในวิดีโอ และไฟล์ตำแหน่ง **.gpx** ข้างคลิป (เปิดใน Google Earth)
- **ล็อกคลิป:** เบรกแรงจะล็อกคลิปปัจจุบันและคลิปก่อนหน้า ล็อกเองได้ คลิปที่ล็อกไม่ถูกลบ
- แท็บ **Playback:** ดู กรอง (ทั้งหมด / ที่ล็อก) และเล่นคลิป

## ควบคุมรถ (หน้า Car)
| ควบคุม | ตัวเลือก | หมายเหตุ |
|---|---|---|
| Acceleration mode | Comfort / Normal / Sport | เปลี่ยนได้ทันที ขณะขับก็ได้ |
| Steering | Comfort / Standard / Sport | ค่าในโหมดขับ Custom ของรถ |
| Damping | Comfort / Standard / Sport | **เฉพาะรุ่น Performance** รถไม่รายงานค่า แอปจึงแสดงค่าล่าสุดที่ส่ง |
| Sunroof shade | ปิด / 25 / 50 / 75 % / เปิด | รถเป็นผู้ตัดสินว่าม่านขยับได้เมื่อไร |
| Rear fog light | เปิด / ปิด | ทำงานเฉพาะตอนเปิดไฟหน้า |
| Low-speed emergency braking | เปิด / ปิด | ปิดแล้วรถจะไม่เบรกให้ที่ความเร็วต่ำ |
| Air conditioning | เปิด / ปิด | |
| Temperature zones | เหมือนกันสองฝั่ง / แยก | |
| Tailgate opening height | 50–100 % | ความสูงที่ประตูท้ายไฟฟ้าเปิด |

**Find a car setting** (อ่านอย่างเดียว): กด **snapshot** เปลี่ยนการตั้งค่าในเมนูรถ แล้วกด **compare** เพื่อดูว่าค่าไหนเปลี่ยน
และ **Search car signals** ค้นสัญญาณรถด้วยคำใดก็ได้ ทั้งสองอย่างไม่เปลี่ยนอะไรในรถ

## Trailer mode (ลากพ่วง)
สำหรับลากรถพ่วง เมื่อระบบเบรกฉุกเฉินความเร็วต่ำอาจเบรกเพราะรถพ่วงด้านหลัง
- **เปิด:** ปิดเบรกฉุกเฉินความเร็วต่ำทันที ทุกครั้งที่สตาร์ทรถ และอีกครั้งเมื่อความเร็วถึง 10 กม./ชม. (กฎอัตโนมัติ 2 ข้อ และเปิด Automation ให้)
- **ปิด:** หยุดกฎเหล่านั้น แต่ **ไม่ได้** เปิดเบรกกลับให้ ต้องเปิดเองที่หน้า Car
- กดค้างที่การ์ดเพื่อดูกฎในหน้า Automation
